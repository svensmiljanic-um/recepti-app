# Primeri uporabe

## Primer uporabe 1

| Polje | Vsebina |
|---|---|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           
| **Primer uporabe:** | Všečkanje |
| **ID:** | Enolična oznaka primera uporabe, na primer PU-01. |
| **Cilj:** | Uporabnik z všečkanjem pokaže svoje pozitino mnenje o nekem receptu. |
| **Akterji:** | Kdo sodeluje (npr. končni uporabnik, sistem, administrator)? |
| **Predpogoji:** | Kaj mora biti izpolnjeno, preden se primer uporabe lahko izvede? |
| **Stanje sistema po PU:** | Ali se stanje sistema spremeni oziroma kakšno je po izvedbi? |
| **Scenarij:** | Opišite običajni potek interakcije uporabnika s sistemom po korakih:<br> 1. Korak 1;<br> 2. Korak 2;<br> 3. … |
| **Alternativni tokovi:** | Opišite možne drugačne poteke in navedite, pri katerem koraku se pojavijo (npr.<br> 1a <br> 1b <br> 2a <br>). |
| **Izjeme:** | Kje lahko pride do napake in kako naj se sistem takrat odzove? |

## Filtriranje receptov po kategorijah

| Polje | Vsebina                                                                                                                                                                                                                                                                                                                                                                                                               |
|---|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Primer uporabe:** | Filtriranje receptov po kategorijah                                                                                                                                                                                                                                                                                                                                                                                   |
| **ID:** | PU-01                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Cilj:** | Uporabnik želi videti samo recepte iz izbrane kategorije, da hitreje najde ustrezen recept.                                                                                                                                                                                                                                                                                                                           |
| **Akterji:** | Gost, registriran uporabnik                                                                                                                                                                                                                                                                                                                                                                                   |
| **Predpogoji:** | Uporabnik pregleduje seznam receptov (PU-01). V sistemu obstaja vsaj ena kategorija.                                                                                                                                                                                                                                                                                                                                  |
| **Stanje sistema po PU:** | Podatki v bazi se ne spremenijo. Seznam receptov je omejen na izbrano kategorijo, dokler uporabnik filtra ne odstrani.                                                                                                                                                                                                                                                                                                |
| **Scenarij:** | 1. Uporabnik na seznamu receptov odpre izbiro kategorij.<br> 2. Sistem prikaže seznam razpoložljivih kategorij.<br> 3. Uporabnik izbere kategorijo.<br> 4. Sistem poišče recepte izbrane kategorije.<br> 5. Sistem prikaže prvo stran ujemajočih receptov in izbrano kategorijo označi kot aktivno.                                                                                                                   |
| **Alternativni tokovi:** | 3a. Uporabnik izbere več kategorij: sistem prikaže recepte, ki spadajo v katero koli od izbranih kategorij.<br> 3b. Uporabnik poleg kategorije vpiše iskalni niz: sistem prikaže recepte, ki ustrezajo obema pogojema.<br> 4a. V izbrani kategoriji ni receptov: sistem prikaže sporočilo »V tej kategoriji še ni receptov«.<br> 5a. Uporabnik izbere »Vse kategorije«: sistem odstrani filter in prikaže vse recepte. |
| **Izjeme:** | - Seznama kategorij ni mogoče naložiti: sistem prikaže sporočilo o napaki, seznam receptov pa ostane nespremenjen in ga je še vedno mogoče pregledovati brez filtra.<br> - Izbrana kategorija medtem ne obstaja več: sistem prikaže obvestilo in osveži seznam kategorij.                                                                                                                                             |

## Komentiranje receptov

| Polje | Vsebina                                                                                                                                                                                                                                                                                                   |
|---|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Primer uporabe:** | Komentiranje receptov                                                                                                                                                                                                                                                                                     |
| **ID:** | PU-02                                                                                                                                                                                                                                                                                                     |
| **Cilj:** | Registriran uporabnik želi pod receptom napisati komentar (mnenje, nasvet ali vprašanje).                                                                                                                                                                                                                 |
| **Akterji:** | Registriran uporabnik                                                                                                                                                                                                                                                                            |
| **Predpogoji:** | Uporabnik je prijavljen. Recept obstaja in je odprt za ogled.                                                                                                                                                                                                                                             |
| **Stanje sistema po PU:** | Komentar je shranjen in viden pod receptom, z imenom avtorja in časom objave.                                                                                                                                                                                                                             |
| **Scenarij:** | 1. Uporabnik pri ogledu recepta izbere polje za komentar.<br> 2. Uporabnik vpiše besedilo in ga potrdi.<br> 3. Sistem preveri, da komentar ni prazen in ni predolg.<br> 4. Sistem shrani komentar.<br> 5. Sistem osveži seznam komentarjev, tako da je nov komentar viden.                                |
| **Alternativni tokovi:** | 2a. Uporabnik prekliče vnos: besedilo se zavrže, komentar ni shranjen.<br> 3a. Komentar je prazen ali presega dovoljeno dolžino: sistem prikaže opozorilo in ostane na obrazcu (nazaj na korak 2).<br> 1a. Uporabnik ni prijavljen (je gost): sistem polja za komentar ne prikaže in ga pozove k prijavi. |
| **Izjeme:** | - Napaka pri shranjevanju: sistem komentarja ne shrani, prikaže sporočilo o napaki in ohrani vneseno besedilo.<br> - Recept je medtem izbrisan: sistem prikaže sporočilo, da recept ne obstaja.                                                                                                           |

## Določitev kategorije recepta

| Polje | Vsebina                                                                                                                                                                                                                                                                                                             |
|---|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Primer uporabe:** | Določitev kategorije recepta                                                                                                                                                                                                                                                                                        |
| **ID:** | PU-03                                                                                                                                                                                                                                                                                                               |
| **Cilj:** | Uporabnik želi receptu ob dodajanju določiti kategorijo, da ga je pozneje mogoče filtrirati (PU-02). Primer uporabe je vključen v PU-05 (Dodajanje novega recepta).                                                                                                                                                 |
| **Akterji:** | Registriran uporabnik                                                                                                                                                                                                                                                                                   |
| **Predpogoji:** | Uporabnik je prijavljen in je v postopku dodajanja recepta (PU-05). V sistemu obstaja vsaj ena kategorija.                                                                                                                                                                                                          |
| **Stanje sistema po PU:** | Recept je ob shranjevanju povezan z izbrano kategorijo.                                                                                                                                                                                                                                                             |
| **Scenarij:** | 1. Uporabnik v obrazcu za nov recept odpre izbiro kategorij.<br> 2. Sistem prikaže seznam razpoložljivih kategorij.<br> 3. Uporabnik izbere kategorijo.<br> 4. Sistem izbrano kategorijo prikaže v obrazcu.<br> 5. Ob shranjevanju recepta sistem zapiše tudi kategorijo.                                           |
| **Alternativni tokovi:** | 3a. Uporabnik kategorije ne izbere: sistem recept shrani v privzeto kategorijo »Brez kategorije«.<br> 3b. Uporabnik izbere več kategorij: sistem recept poveže z vsemi izbranimi.<br> 5a. Izbrana kategorija medtem ne obstaja več: sistem prikaže opozorilo in uporabnika pozove k novi izbiri (nazaj na korak 3). |
| **Izjeme:** | - Seznama kategorij ni mogoče naložiti: sistem omogoči shranjevanje recepta brez kategorije in prikaže opozorilo.<br> - Napaka pri shranjevanju: sistem recepta ne shrani, ohrani vnesene podatke v obrazcu in prikaže sporočilo o napaki.                                                                          |

## Brisanje receptov

| Polje | Vsebina                                                                                                                                                                                                                                                                             |
|---|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Primer uporabe:** | Brisanje receptov                                                                                                                                                                                                                                                                   |
| **ID:** | PU-04                                                                                                                                                                                                                                                                               |
| **Cilj:** | Administrator želi odstraniti neprimeren ali neustrezen recept katerega koli uporabnika.                                                                                                                                                                                            |
| **Akterji:** | Administrator                                                                                                                                                                                                                                                                       |
| **Predpogoji:** | Administrator je prijavljen. Recept obstaja.                                                                                                                                                                                                                                        |
| **Stanje sistema po PU:** | Recept je izbrisan iz baze, skupaj z njegovimi všečki in komentarji. Recept ni več viden nikomur.                                                                                                                                                                                   |
| **Scenarij:** | 1. Administrator odpre recept ali seznam receptov.<br> 2. Administrator izbere možnost »Izbriši recept«.<br> 3. Sistem zahteva potrditev brisanja.<br> 4. Administrator potrdi.<br> 5. Sistem izbriše recept in povezane podatke.<br> 6. Sistem osveži seznam in prikaže potrditev. |
| **Alternativni tokovi:** | 4a. Administrator prekliče brisanje: recept ostane nespremenjen.<br> 2a. Dostop do možnosti poskuša uporabnik brez vloge administratorja: sistem možnosti ne prikaže, zahtevo pa zavrne.                                                                                            |
| **Izjeme:** | - Recept je medtem že izbrisan: sistem prikaže obvestilo in osveži seznam.<br> - Napaka pri brisanju: sistem recepta ne izbriše, prikaže sporočilo o napaki.                                                                                                                        |

## Brisanje komentarjev

| Polje | Vsebina                                                                                                                                                                                                                                                        |
|---|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Primer uporabe:** | Brisanje komentarjev                                                                                                                                                                                                                                           |
| **ID:** | PU-5                                                                                                                                                                                                                                                           |
| **Cilj:** | Administrator želi odstraniti neprimeren komentar pod receptom.                                                                                                                                                                                                |
| **Akterji:** | Administrator                                                                                                                                                                                                                                            |
| **Predpogoji:** | Administrator je prijavljen. Komentar obstaja.                                                                                                                                                                                                                 |
| **Stanje sistema po PU:** | Komentar je izbrisan in ni več viden pod receptom. Recept se ne spremeni.                                                                                                                                                                                      |
| **Scenarij:** | 1. Administrator odpre recept s komentarji.<br> 2. Pri neprimernem komentarju izbere možnost »Izbriši komentar«.<br> 3. Sistem zahteva potrditev brisanja.<br> 4. Administrator potrdi.<br> 5. Sistem izbriše komentar.<br> 6. Sistem osveži seznam komentarjev. |
| **Alternativni tokovi:** | 4a. Administrator prekliče brisanje: komentar ostane.<br> 2a. Pod receptom ni komentarjev: možnost brisanja ni prikazana.                                                                                                                                      |
| **Izjeme:** | - Komentar je medtem že izbrisan: sistem prikaže obvestilo in osveži seznam.<br> - Napaka pri brisanju: sistem komentarja ne izbriše in prikaže sporočilo o napaki.                                                                                            |
